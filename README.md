# 【総合ドキュメント】ARスポーツ『HADO』のVRChat移植・開発仕様書

本ドキュメントは、現実のARテクノスポーツ『HADO』の基本ルール、VRChatへ移植する際の企画拡張アイデア、VFX/SFXの要件、およびUdon（UdonSharp）を用いたテクニカルな実装仕様までを網羅した総合開発仕様書である。

---

## 1. 原作『HADO』の基本ルール概要

『HADO（ハドー）』は、頭にヘッドマウントディスプレイ、腕にアームセンサーを装着し、自らの手からエナジーボールを放って戦うAR（拡張現実）テクノスポーツである。

### 1.1 基本的な試合の流れ
* **試合人数:** 基本は 3人 vs 3人（計6名）
* **試合時間:** 1試合 80秒。
* **勝敗条件:** 時間内により多くの点数（KO数）を獲得したチームの勝ち。
* **サドンデス:** タイムアップ時に同点の場合、時間無制限の延長戦へ移行。先に1点先取したチームが勝利。

### 1.2 得点（KO）システム
各プレイヤーの前面には、4つの「ライフ」が浮遊している。
* 相手のエナジーボールがこのライフに当たると、ライフが1つ破壊される。
* 4つのライフをすべて破壊すると「KO（ダウン）」となり、相手チームに1点が入る。
* 倒されたプレイヤーは数秒後にライフが全回復した状態でその場にリスポーンする。

### 1.3 プレイヤーアクション
* **エナジーボール（攻撃）:** 両肩に透明なオブジェクトを追従させ、そのオブジェクトを投げることでエナジーボールが出現する。
* **シールド（防御）:** 腕を下げることでゲージを溜め、勢いよく腕を振り上げると、目の前に相手の弾を防ぐ光の壁（シールド）が出現する。1人あたり1試合に1回のみ使用可能。
* **回避（運動）:** 体を左右に動かしたり、しゃがんだりしてリアルに弾を避ける。

### 1.4 パラメーターカスタム
合計6ポイントを、以下の4つの能力に自由に振り分けて戦う（1項目最大5ポイント）。
1. **弾速:** エナジーボールの飛ぶスピード。
2. **弾のサイズ:** ボールの大きさ（大きいほど相手に当たりやすい）。
3. **チャージスピード:** 次の弾を撃つまでのチャージ時間短縮。
4. **シールドの強さ:** シールドの耐久値。

## 2. VRChat移植における企画・拡張アイデア（VRの特権）

完全なバーチャル空間であるVRChatでは、現実の物理制限やARの表現限界を超えた、以下のような強力な機能やルールを追加できる。

### 2.1 プレイヤーの移動・視界に影響させる
ARグラスでは不可能な移動・視界への干渉。
* **低重力:** ふわふわと浮く。

### 2.2 動く壁・ワープ！「ステージの動的ギミック」
* **跳ね返る「バウンド弾」と移動する遮蔽物:** ステージ中央の壁が自動で動き、エナジーボールが壁に当たると反射する。
* **空間を繋ぐ「ポータル（ワープ）」:** ステージの左右にポータルを設置し、プレイヤーだけでなく、撃った弾をポータルに滑り込ませて相手の背後から奇襲させることができる。

### 2.3 物理法則を無視した「魔球システム」
* **湾曲弾（カーブ）:** コントローラーをひねりながら撃つと、弾が左右に大きくカーブする。
* **遠隔炸裂（リモート爆破）:** 弾を撃った後、もう一度トリガーを引くと空中爆発し、周囲のライフを巻き込む。

### 2.4 知覚ハックとアバター連動
* **レイドボスモード（1 vs 3）:** 1人だけが「身長10メートル」の巨人になり、残りの3人は「身長50センチ」の小人になって戦う非対称バトル。

## 3. VFX / SFX アセット要件定義

VR空間での臨場感、およびゲームとしての「視認性・爽快感」を確保するために必要なアセットのリスト。

### 3.1 VFX（視覚効果・パーティクル・シェーダー）
* **攻撃関連:**
  * チャージ中の集光エフェクト（手元に光が集まる演出）。
  * 弾丸本体＋トレイル（飛んでいる弾の後ろに尾を引く軌跡エフェクト）。
  * 壁・シールド着弾時のスパーク。
  * プレイヤー被弾時の激しい破裂演出。
* **防御関連:**
  * シールド展開時のアニメーション（光の壁がパッと広がる演出）。
  * シールドのホログラム質感（サイバーなグリッド柄のカスタムシェーダー）。
  * 被弾時のヒビ割れ、および耐久値ゼロでのガラス粉砕エフェクト。
* **システム関連:**
  * カウントダウン「3, 2, 1, FIGHT!」の3Dテキストエフェクト。
  * 試合中の「KO」「TIME UP」の動的文字演出。
  * ライフ（4つの的）が破壊される際の一小爆発演出。

### 3.2 SFX（音響効果）
* **戦闘アクション音:**
  * エナジーボール：チャージ音（ウィイインと上昇する音）、発射音（シュパッ！）、飛行音（接近を察知するためのループ風切り音）、着弾音。
  * シールド：展開音（バシィィン！）、防御音（弾を弾く金属音）、崩壊音（パリィィィン！）。
* **システム・環境音:**
  * BGM（テクノスポーツに合う、テンポの速いサイバー・エレクトロ系のバトル曲）。
  * システムボイス（「Ready?」「Fight!」「KO!」「Game Over!」などのアナウンス）。
  * リスポーン音（プレイヤーが復活した時のシュイーンという音）。

## 4. HADO VR テクニカル実装仕様書

### 4.1 基本仕様
* **開発環境:** Unity 2022.3.22f1 / VRChat SDK3 (World) / UdonSharp (U#)
* **対象プラットフォーム:** PC / VR (クロスプラットフォーム対応)
* **最大プレイ人数:** 10名（5 vs 5）

### 4.2 ネットワーク・同期設計（ラグ対策）
* **ゲームステート管理:** 試合の進行状態はインスタンスのOwnerが一括管理し、`[UdonSynced]` 変数を用いて全員に同期する。
* **オブジェクトプール:** 弾（エナジーボール）の生成・管理には `VRC_ObjectPool` を使用する。
* **ヒット判定（最重要）:** **「食らい手（被弾側）ローカル最優先」**方式を採用。弾が衝突したプレイヤーのローカル画面で `OnTriggerEnter` を検知した瞬間に判定を行う。これにより、ネットワーク遅延による不公平感を完全に排除する。

### 4.3 ステージ・レイアウト仕様
* **コートサイズ:** 横 10.0m × 縦 15.0m
* **エリア制限:** センターライン上に、プレイヤー自身（LocalPlayer / Playerレイヤー）のみが侵入できないコライダーを配置。弾オブジェクトはこれを透過する。
* **アバターサイズの共通化:** エントリー時に全プレイヤー共通のゲーム用カプセルコライダー（高さ 1.6m / 半径 0.3m）を強制適用し、トラッキング位置に追従させることで、アバターのサイズ差による有利不利をなくす。

### 4.4 入力・操作仕様

| アクション | VRモード（3Dトラッキング） | PCデスクトップモード |
| :--- | :--- | :--- |
| **エナジーボール** | 手が頭部より上の位置（Y座標比較）で**チャージ**。<br>腕を前に突き出す（またはトリガー）で**発射**。 | `【Qキー】` 長押しで**チャージ**。<br>`【マウス左クリック】` で視点正面へ**発射**。 |
| **シールド** | 手を腰より下の位置で**ゲージ蓄積**。<br>満タン時に腕を振り上げて前方1mに**生成**。 | `【Eキー】` 長押しで**ゲージ蓄積**。<br>`【マウス右クリック】` で正面に**生成**。 |

### 4.5 VRChat独自拡張機能の実装
* **リアルタイム実況モニター（RenderTexture）:** コート全体を追従するカメラ映像を観客席の巨大スクリーンに投影。現在のスコアや残り時間をオーバーレイUIとして合成表示する。
